# Case 12 assets

The notebook illustration is original. Recreate its oversized PNG and compact WebP with `node scripts/case-12-assets.mjs` from the React app. The PNG deliberately retains fine paper texture and excessive dimensions; the WebP shows the same artwork at a suitable resolution.

The local DM Sans Latin regular web font comes from `@fontsource/dm-sans` 5.3.0 and retains its SIL Open Font License in `FONT-LICENSE.txt`. Both variants use the same font bytes; only discovery and display behavior differ.
